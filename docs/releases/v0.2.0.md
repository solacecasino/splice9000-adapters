# splice9000 adapters 0.2.0

Three adapters, and every compiled one now runs on every kind of computer
splice9000 does, with no Python needed.

| Adapter | Adds | Downloads |
|---|---|---|
| **Silence Cut** 0.1.0 (new) | **Edit → Remove Silences** (⌘⇧J): takes the silent stretches out of a clip, leaving a little room around words. Jump cuts for talking video, as one undo step. | Mac (Apple Silicon, Intel), Windows (x64, Arm), Linux (x64, Arm) |
| **Loudness Normalize** 0.1.0 (new) | Export formats that level the sound to −14 LUFS (YouTube, Spotify), −16 LUFS (podcasts, sound only) or −23 LUFS (EBU R128 broadcast). Presets only: nothing of it runs. Needs splice9000 0.0.6. | One zip for every computer |
| **Scene Split** 0.2.0 | Same as 0.1.0, rewritten in Rust: it no longer needs Python, so it works on Windows out of the box. | Mac (Apple Silicon, Intel), Windows (x64, Arm), Linux (x64, Arm) |

Download the zip for your computer from the
[catalog](https://github.com/solacecasino/splice9000-adapters/blob/main/CATALOG.md)
and drop it on splice9000's window. Scene Split 0.2.0 replaces 0.1.0 when
you drop it on.

## Tested

On each of the six machines (macOS Apple Silicon and Intel, Windows x64 and
Arm, Linux x64 and Arm), with that machine's ffmpeg:

- Scene Split, run the way splice9000 runs it, cuts a three-scene clip at
  exactly 2.0 and 4.0 seconds.
- Silence Cut takes the 1.5-second silence out of a sound–silence–sound
  clip and keeps both sounds with room around them (0–1.12 s and
  2.38–3.5 s).
- Each Loudness Normalize format, measured with ffmpeg's EBU R128 meter
  after leveling a quiet recording (−37.9 LUFS), lands within 1 LU of its
  target (−14.4, −16.4 and −23.4 LUFS on a Mac).

## For adapter makers

- [`sdk/rust/splice.rs`](../../sdk/rust/splice.rs): a one-file Rust helper,
  like `splice.py`. Scene Split and Silence Cut are each about 100 lines on it.
- Compiled adapters are built for six platforms (`macos-arm64`, `macos-x64`,
  `windows-x64`, `windows-arm64`, `linux-x64`, `linux-arm64`), named for what
  Rust built rather than what the build machine's Python reports.
