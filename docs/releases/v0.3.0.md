splice9000's editing tools, as adapters. Each one comes with splice9000 0.0.7, and each can be removed there, added back, or installed from here. All need splice9000 0.0.7.

- **Waveforms** (new): each clip's sound drawn on the timeline, so you can see words, beats and silences without playing. A file is read once and kept in splice9000's cache.
- **Thumbnails** (new): pictures from each clip along it on the timeline. Long files are read a keyframe at a time, so an hour of video takes seconds.
- **Shuttle** (new): J/K/L playback. L plays, and each press goes faster, up to 8x; J does the same backward; K stops. Pressing the other way slows down first.
- **Snapping** (new): while dragging, the playhead snaps to cuts and a clip's end snaps to the playhead. Hold Alt (Option) to drag freely. It's settings only, so nothing of it runs.
- **Crossfades** (new): Edit → Crossfade at Nearest Cut (⌘D), Remove Crossfade (⌘⇧D), Crossfade Every Cut, Remove All Crossfades and Crossfade Length…. The fade is centered on the cut and doesn't change the edit's length. Where a clip has no footage past the cut, its last or first picture holds.

The Rust SDK (`sdk/rust/splice.rs`) gains `serve` for adapters that start working on launch or listen to events, `post` for reporting from background threads, and `playback`. The Python SDK gains `playback`. `plain_clips` now keeps crossfades.

Each Rust adapter is built and tested on six kinds of computer (Mac Apple Silicon and Intel, Windows x64 and Arm, Linux x64 and Arm) by driving its program the way splice9000 does, with real ffmpeg: `scripts/test_editing.py`.
